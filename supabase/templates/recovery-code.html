Código temporário do MCR

Recebemos uma solicitação para recuperar o acesso à sua conta do Meu Controle de Rendimento.

Digite este código na tela de recuperação do MCR:

{{ .Token }}

O código é temporário e de uso único. Depois de validá-lo, você poderá definir uma nova senha.

Se você não solicitou a recuperação, ignore esta mensagem. Sua senha atual não será alterada sem a validação do código.
